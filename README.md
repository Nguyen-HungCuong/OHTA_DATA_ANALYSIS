# PYTHON FOR OHTA DATA ANALYSIS

## 1. Project Overview
This is an independent data analysis project developed using Python to automate supply chain data workflows and optimize material planning. The tool extracts raw, flat data (Sales Orders, Inventory) from ERP system, applies advanced supply chain logic, and generates structured, decision-ready Excel reports.


---

## 2. Business Problems Addressed
In distribution and manufacturing environments, managing supply chain data manually through standard spreadsheet operations is highly time-consuming and prone to human error. This project simulates and solves three core supply chain challenges:

1. **Stock vs. Demand Gap:** Detecting immediate material shortages by matching available warehouse stock against current Sales Orders (SO).
2. **ABC and XYZ Analysis:** Filtering the critical items to analyze the planning
3. **SO Backlog & Allocation:** Managing delayed orders by calculating backlog aging days and prioritizing material allocation based on Bill of Materials (BOM) importance.
4. **Dynamic Reorder Points (ROP):** Mitigating supplier lead-time volatility to maintain optimal safety stock levels without over-inflating inventory costs.
5. **Forecast Accuracy & Bias:** Proposing and validating the suitable forecast models.
